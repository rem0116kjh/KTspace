# ORBIT LAB · 태양계 WHAT IF 실험실

중학생도 바로 시작할 수 있는 **쉽게 시작하기**가 기본 화면입니다. 태양의 질량을
100%·80%·50% 버튼으로 바꾸며 지구가 도는 길과 한 바퀴 도는 시간을 비교합니다.
**심화 탐구**로 전환하면 이심률·에너지 오차·모델 비교와 기존의 모든 설정을 확인할 수 있습니다.

화면 위 **어떤 실험을 해 볼까요?** 또는 **실험 모음**에서 아래 10가지 종류를
선택할 수 있습니다. 실험마다 전용 조절 막대와 빠른 비교 버튼이 나타나며,
조건을 바꾸면 Python이 수치·그래프·쉬운 설명을 다시 계산합니다.

| 실험 | 바꾸는 조건 | 비교하는 결과 |
|---|---|---|
| 태양의 질량 | 질량·처음 거리·초기 속도 모델 | 지구의 궤적·공전 주기·에너지 오차 |
| 블랙홀 | 질량·지구와의 거리 | 중력·조석 효과·사건의 지평선 크기 |
| 지구의 질량 | 반지름을 고정한 질량 | 표면 중력·무게·탈출 속력 |
| 시리우스 A | 지구와의 거리 | 태양과 별의 합산 빛·모형 온도·별의 중력 |
| 태양과의 거리 | 궤도 반지름 | 햇빛·모형 온도·원궤도 공전 주기 |
| 지구의 자전 | 자전 한 바퀴의 시간 | 적도의 유효중력·지표 속력 |
| 태양의 밝기 | 현재 대비 밝기 | 받는 에너지·모형 온도 |
| 지구의 반사율 | 반사하는 빛의 비율 | 반사·흡수 에너지·모형 온도 |
| 지구의 대기 | 현재 대비 대기의 양 | 선형으로 가정한 온실효과·모형 온도 |
| 지구의 자기장 | 현재 대비 세기 | 일정한 태양풍에서 자기권 경계 거리 비 |

태양 질량 실험은 기존 2체 궤적을 적분합니다. 다른 실험도 태양과 8개 행성이
움직이는 공통 화면을 제공하며, 전체 태양계/안쪽 행성 전환, 재생·일시 정지,
속도 변경과 시간 막대를 지원합니다. 지구 확대에서는 자전 속도·대기의 양·반사광·
자기권 등 선택한 조건이 표시됩니다.

블랙홀·시리우스 A 실험은 태양과 추가 천체를 고정한 두 중력장에서 8개 행성의
시험입자 궤적을 적분합니다. 실제 태양·추가 천체의 이동과 행성 상호작용은
생략합니다. 0.025 AU 이내의 근접에서는 해당 궤적을 끝내며, 충돌·포획으로
판정하지 않습니다. 그 외 실험은 원궤도 공전을 보여주고, 거리 실험에서만
지구의 원궤도 반지름을 바꿉니다. 실제 기후의 시간 변화는 적분하지 않습니다.

행성의 거리 간격은 방사 방향으로 압축하고 천체 크기를 확대합니다. 지구 자전
확대는 비교를 위한 별도의 느린 시간 배율입니다. 수치 표는 시작 순간의 조건을
기준으로 하므로, 시간이 흐른 뒤의 거리와 다시 계산한 값으로 해석하지 않습니다. 온도 실험에는 같은 복사 평형식과
온실효과 가산값을 사용합니다. 자기권 실험은 쌍극자 근사이며 지상 방사선량을
예측하지 않습니다. 화면에서 각 공식과 가정, 기준값 비교 표를 확인할 수 있습니다.

모든 실험을 기존 노트와 함께 저장·다시 실행하고 CSV로 내보낼 수 있습니다.
기존 브라우저 노트의 저장 키와 궤도 노트 형식은 유지합니다. 기본 실험실과
새 화면은 `simulation_engine.py`의 계산을 공유하며, API 키 없이 동작합니다.

- 순서 안내와 처음 사용 방법, 쉬운 용어 풀이, 큰 글씨와 조작 버튼
- 계산 결과에서 만든 쉬운 설명: 원·타원·탈출을 구분하며 열린 궤도에 주기를 표시하지 않음
- 내 예상 선택 → 결과와 비교 → 관찰 문장을 시작하는 도움과 노트 기록
- 거리·출발 속도 등 추가 조건은 접어 두고 필요할 때 펼쳐 보기

- 네 가지 탐구: 질량과 궤도, 탈출 경계, 케플러 법칙, 수치 적분 오차
- 해석식으로 계산한 궤도 요소와 Velocity Verlet로 적분한 실제 궤적
- 에너지 보존 그래프, 동일 초기 거리의 기준 궤도, 두 모델 비교 표
- 가설·관찰·설명을 남기는 브라우저 탐구 노트와 JSON 백업
- 초기 조건과 시간별 궤적·에너지 오차를 포함한 CSV 내보내기
- 외부 폰트·이미지·JavaScript CDN 없이 실행되는 반응형 화면

### 심화 모델의 가정

고정된 중심 천체와 질량을 무시한 행성의 2체 문제입니다. AU·태양질량·율리우스년
(365.25일) 단위에서 `G = 4π²`를 씁니다. 순간 변화 모델은 원래 태양에 대한
원궤도 속도를 유지합니다. 원궤도 비교는 변경된 질량에 맞는 초기 속도를 쓰며,
실제의 느린 질량 감소 과정을 적분하는 모델이 아닙니다.

공전 주기·이심률·근일점·원일점은 해석식으로 계산하며, 애니메이션은 Python에서
수치 적분한 궤적을 사용합니다. 에너지 오차는 질량 변경 직후를 기준으로
`Δε/(GM₀/r₀)`를 측정하며, 포물선의 에너지가 0인 경우에도 유효합니다.
모든 적분 단계에서 최대 오차를 검사합니다. 적분 기간은 2~6년입니다.

검증:

```bash
python3 -m unittest -q test_orbital_dynamics
python -m pytest -q
```

이하 설명은 기존 **기본 실험실**의 기능과 가정입니다.

않으며, AI는 계산된 값을 초보자 눈높이로 설명하는 역할만 합니다.

## 개요

태양 질량, 지구 질량, 블랙홀, 시리우스 A 같은 조건을 변화시켜
행성의 공전 주기, 표면 중력, 상대 중력·조석력, 복사 에너지를 계산합니다.
결과를 표와 그래프로 비교하며, 천체 운동과 지구 환경이 질량·거리·빛의 세기에
따라 어떻게 달라지는지 탐구합니다.

## 배울 내용

- 태양계의 구성과 행성의 특징, 태양의 중력이 행성 공전에 미치는 영향
- 케플러 제3법칙: 태양 질량 변화에 따른 공전 주기 변화
- 중력의 거리 의존성: 천체 질량이 클수록, 거리가 가까울수록 중력이 커짐
- 조석력의 상대 비교: 블랙홀 같은 극한 상황에서 천체 간 영향 분석
- 복사 에너지와 복사 평형 온도: 별의 밝기와 거리가 지구 환경에 주는 영향
- 과학적 모델의 한계: 가정과 실제 자연현상의 차이 평가

## 교과 연계

**중학교** (천재교과서 중학교 과학 「태양계」 단원)  
태양계는 태양과 행성, 위성, 소행성으로 이루어져 있으며, 태양의 중력은 행성의 공전을 설명합니다.
별빛과 열의 복사 에너지는 지구 환경에 영향을 줍니다.

**고등학교** (천재교과서 고등학교 「통합과학」 또는 「행성우주과학」)  
행성의 공전은 태양의 중력으로 설명할 수 있으며, 공전 주기는 태양으로부터의 거리와
태양의 질량에 따라 달라집니다. 별의 광도와 거리는 행성이 받는 복사 에너지에 영향을 줍니다.

## 데이터 내보내기 (CSV)

기본 실험실의 시뮬레이션 결과는 `data.csv` 파일에 자동으로 저장됩니다.

**포함되는 데이터:**
- `timestamp`: 실행 시간 (ISO 8601 형식)
- `scenario_type`: 시나리오 타입 (sun_mass, earth_mass, blackhole, sirius 등)
- `scenario_title`: 시나리오 제목
- `scenario_params`: 시뮬레이션 파라미터 (JSON)
- `results`: 계산 결과값 (JSON)
- `risk_score`: 지구 거주 가능성 영향 지수 (0–100)
- `ai_interpretation`: AI 해석 텍스트 (있을 경우)

**CSV 정보:**
- 인코딩: UTF-8
- 구분자: 쉼표
- 헤더: 첫 행에 컬럼명 포함
- 누적 저장: 기존 데이터 보존

## 시나리오와 가정

| 시나리오 | 기본 가정 | 주요 계산 |
|---|---|---|
| 태양 질량 변화 | 행성 거리 고정 | 케플러 제3법칙에 따른 공전 주기 |
| 지구 질량 변화 | 지구 반지름 고정 | 표면 중력 변화 |
| 블랙홀 출현 | 10 태양질량, 지구에서 1 AU, 갑작스런 출현 | 중력 `M/r²`, 조석력 `M/r³` 상대 비교 |
| 시리우스 A 출현 | 질량 2.063배, 광도 24.7배, 1 AU | 복사량과 복사 평형 온도 근사 |

블랙홀 시나리오의 핵심은 1 AU에서 지구가 즉시 찢어지는 현상이 아니라,
갑자기 추가된 강한 중력으로 태양계의 기존 궤도가 크게 교란되는 것입니다.
시리우스 온도는 대기, 해양 순환, 온실효과를 생략한 단순 근사치입니다.

화면의 0–100 위험 지수는 절대적인 과학 단위가 아니라 시나리오 간 교육용
상대 비교 값입니다.

## 탐구 결과

**태양 질량 변화**  
태양의 질량이 증가하면 같은 거리에서 행성의 공전 주기는 짧아집니다.
이는 태양 질량이 커질수록 행성에 작용하는 중력이 강해지기 때문입니다.

**지구 질량 변화**  
지구 반지름을 고정할 경우, 표면 중력은 지구 질량이 증가할수록 커집니다.

**블랙홀 출현**  
지구에서 1 AU 떨어진 위치에 10태양질량 블랙홀이 갑자기 나타나면,
지구가 바로 찢어지는 현상보다 태양계의 기존 행성 궤도가 불안정해질 가능성이 큽니다.

**시리우스 A 출현**  
시리우스 A가 1 AU 거리에 존재한다면 태양보다 큰 광도(모형 값 24.7배)로 인해
지구가 받는 복사 에너지가 크게 늘어나고, 복사 평형 온도도 크게 상승합니다.

**태양 질량 변화의 두 모델**  
태양 질량이 바뀔 때 궤도가 어떻게 변하는지는 변화의 "과정"에 따라 달라집니다.
모델 A는 태양이 원래부터 그 질량이었다면 지구는 그 질량의 태양 주위에서
원궤도를 유지합니다. 모델 B는 지구의 속도와 위치를 고정한 채 태양이 갑자기 질량이
변한다면, 새로운 중력장에서 지구는 타원 궤도나 쌍곡선 궤도로 변하게 됩니다.

**태양 질량 절반 시 탈출 궤도**  
태양 질량이 절반으로 줄어들면(μ = 0.5), 이심률 공식 e = |μ − 1|/μ에서
e = |0.5 − 1|/0.5 = 1이 되어 지구의 궤도가 포물선(탈출 궤도)이 됩니다.
이는 지구의 공전 속도가 더 이상 태양의 중력에 묶이지 않을 정도로 높아진다는 뜻입니다.
