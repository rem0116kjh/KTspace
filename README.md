# 태양계 WHAT IF 실험실

태양이나 지구의 질량이 달라지거나, 블랙홀·시리우스 A가 가까이 나타나는
가상 상황을 비교하는 교육용 시뮬레이션입니다. 계산 결과는 AI가 만들지
않으며, AI는 계산된 값을 초보자 눈높이로 설명하는 역할만 합니다.

## 빠른 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 solar_system_sim_v2_openai.py
python3 solar_system_dashboard.py
```

직접 플레이하려면 다음 명령을 실행합니다.

```bash
streamlit run app.py
```

브라우저에서 50개 프리셋 중 하나를 고를 수 있습니다. `조건 직접 조정`을
켜면 질량·거리 값을 움직일 때 결과가 즉시 바뀝니다.
태양계 그림에서는 수성부터 해왕성까지 8개 행성이 모두 움직이며, 애니메이션
속도를 바꾸거나 움직임을 멈출 수도 있습니다.

생성된 대시보드는 `dashboard.png`에서 확인할 수 있습니다.

## AI 해설 사용하기

AI API는 선택 사항입니다. API가 없거나 호출에 실패해도 검증된 기본 해설로
계속 실행됩니다.

```bash
cp .env.example .env
```

`.env` 파일의 `OPENAI_API_KEY`에 새로 발급한 키를 입력합니다. 실제 키는
코드, 화면 캡처, 채팅 또는 Git 저장소에 올리지 마세요.

## 시나리오와 가정

| 시나리오 | 기본 가정 | 주요 계산 |
|---|---|---|
| 태양 질량 변화 | 행성 거리 고정 | 케플러 제3법칙에 따른 공전 주기 |
| 지구 질량 변화 | 지구 반지름 고정 | 표면 중력 변화 |
| 블랙홀 출현 | 10 태양질량, 지구에서 1 AU, 갑작스런 출현 | 중력 `M/r²`, 조석력 `M/r³` 상대 비교 |
| 시리우스 A 출현 | 질량 2.02배, 광도 25.4배, 1 AU | 복사량과 복사 평형 온도 근사 |

블랙홀 시나리오의 핵심은 1 AU에서 지구가 즉시 찢어지는 현상이 아니라,
갑자기 추가된 강한 중력으로 태양계의 기존 궤도가 크게 교란되는 것입니다.
시리우스 온도는 대기, 해양 순환, 온실효과를 생략한 단순 근사치입니다.

화면의 0–100 위험 지수는 절대적인 과학 단위가 아니라 시나리오 간 교육용
상대 비교 값입니다.
