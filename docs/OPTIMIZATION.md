# 태양계 WHAT IF 실험실 최적화

2026-10-18, 기준 커밋 `e626955bbf4be3b132c77ece24002c338351b51b`.
물리 모델·적분 해상도·응답의 수치와 설명·노트 저장 형식은 유지했다.
최적화 범위는 두 가지로 제한했다.

1. 추가 천체의 궤적을 그릴 때, 변하지 않는 화면 좌표와 행성 표시 순서를
   재사용한다. 새 실험 수신·캔버스 크기·전체/안쪽 보기 변경 시 좌표를 갱신한다.
   현재 행성 위치는 기존과 같이 물리 좌표에서 보간한 뒤 화면에 투영한다.
2. 로컬 미리보기 서버는 검증·정규화한 설정에 따라 직렬화한 응답 바이트를
   최대 16개 보관한다. JSON 공백을 줄이고, 클라이언트가 허용하면 gzip 레벨 3으로
   보낸다. 압축 거부(`gzip;q=0`)에는 일반 JSON을 보낸다. 브라우저 HTTP 캐시는
   계속 `no-store`이며 노트·파일·API 키는 이 캐시에 들어가지 않는다.

첫 번째 변경은 Streamlit과 미리보기 양쪽에 적용된다. 두 번째는 `preview.py`에만
적용된다. 공개 Streamlit 서비스의 배포 속도나 네트워크 왕복 시간을 측정한 결과는 아니다.

## 측정 방법

macOS 27.0.1 arm64, Python 3.15.0, Node 26.10.0. 동일 입력으로 기준 → 변경을
두 차례 순차 실행했다. 백엔드는 8회 준비 후 80회씩 5개 묶음의 호출당 경과
시간 중앙값을 기록했다. JSON 생성·압축·검증·캐시 조회를 포함하며, HTTP·브라우저
파싱·렌더링 시간은 포함하지 않는다. 각 경우의 두 측정 중앙값을 아래에 나란히 썼다.

| 조건 | 반복 응답 생성 ms, 기준 | 반복 응답 생성 ms, 변경 | 본문 바이트, 기준 → 변경 |
|---|---:|---:|---:|
| 태양 질량 기본값 | 2.62249 / 2.62259 | 0.00123 / 0.00128 | 65,590 → 26,228 |
| 블랙홀 질량 10배·거리 1 AU | 2.94834 / 2.93397 | 0.00102 / 0.00103 | 155,179 → 65,339 |
| 시리우스 A 거리 5 AU | 4.01592 / 4.00008 | 0.00073 / 0.00074 | 208,076 → 85,287 |
| 지구 자전 12시간 | 4.63780 / 4.58665 | 0.00074 / 0.00072 | 235,818 → 87,331 |

본문 크기는 압축을 지원하는 요청에서 약 58~63% 감소했다. **새 설정의 첫 요청**은
압축 비용이 추가된다. 준비 전 첫 요청은 태양 약 2.8~2.9 → 3.7~3.8 ms,
블랙홀 29.9~30.2 → 32.7~32.8 ms, 시리우스 41.7~42.1 → 44.8 ms,
자전 5.7~5.9 → 9.1~9.4 ms였다. 첫 요청은 각 회당 한 번만 관찰했으므로 통계적
개선 주장에 사용하지 않는다. 반복 설정의 재사용과 전송량 감소가 목적이다.

화면 계산은 동일한 Python 궤적을 Node VM의 동일한 모의 Canvas에 전달했다.
80프레임 준비 후 160프레임씩 5개 묶음의 중앙값을 구하고 두 번 비교했다.
아래 값은 그리기 함수의 CPU 비용이며 **실제 브라우저 FPS나 GPU 측정값이 아니다.**

| 조건 | 프레임당 ms, 기준 | 프레임당 ms, 변경 | 관찰 |
|---|---:|---:|---|
| 블랙홀 | 1.588 / 1.589 | 0.342 / 0.338 | 약 79% 감소 |
| 시리우스 A | 2.031 / 2.029 | 0.386 / 0.383 | 약 81% 감소 |
| 자전 비교용 원궤도 | 0.196 / 0.196 | 0.190 / 0.191 | 큰 차이 없음 |

모의 Canvas는 실제 픽셀을 그리지 않는다. 그리기 명령·좌표·스타일·순서의
SHA-256을 기준과 비교했다. 세 조건 모두 0/23/71/100% 시간, 전체/안쪽 보기,
640×440/340×380 크기, 다른 궤적 수신 후 복귀에서 일치했다. 두 번의 백엔드
측정에서도 압축 해제 후 전체 JSON 내용의 해시가 기준과 일치했다.

## 재현과 회귀 검사

```bash
python3 -S scripts/benchmark_lab.py --baseline e626955
python -m pytest -q
node --check orbit_ui/app.js
node --check orbit_ui/solar-view.js
git diff --check
```

벤치마크는 Git의 기준 소스를 임시 폴더에 추출해 순차 비교한다. 의존성은 Python
표준 라이브러리와 Node뿐이다. 실패 시 종료 코드가 0이 아니며, 성공 시 실행별
시간·바이트 수·내용 해시를 JSON으로 출력한다. 사용자 노트나 `data.csv`를 읽거나
수정하지 않는다. 기본 물리 회귀와 압축 협상·캐시 상한·잘못된 요청·실제 HTTP
전송 검사를 합쳐 **123개 테스트와 65개 하위 검사가 통과**했다.

로컬 미리보기와 실제 Streamlit 화면에서도 시리우스 A의 계산 완료·8개 행성·
애니메이션 진행을 확인했다. 미리보기에서 태양 질량 50%, 블랙홀 거리 1→2 AU,
전체/안쪽 보기 전환과 73일째로 시간 이동도 확인했으며 JavaScript 오류가 없었다.
점검 전후 기존 `data.csv`의 SHA-256과 Streamlit 노트 개수(1개)를 유지했다.
